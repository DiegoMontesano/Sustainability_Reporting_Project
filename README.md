# Sustainability_Reporting_Project
## Repository Contents

## Project Overview

This repository contains the materials developed for a sustainability reporting analysis project focused on evaluating the quality, credibility, and strategic integration of non-financial disclosures.

## Quality Analysis

A key component of the project is the quality analysis of the sustainability report. This analysis combines both qualitative and quantitative approaches to evaluate the clarity, readability, and credibility of the disclosed information.

The assessment includes:

* Linguistic and readability analysis (e.g., sentence complexity and readability indices)
* Evaluation of tone and potential impression management
* Identification of vague or non-committal language
* Topic modeling to assess the distribution of environmental, social, and governance content

These methods are used to determine whether the report communicates information in a transparent and decision-useful manner or whether complexity and language are used to obscure key issues.

## Code Description

This repository includes the Python code used to perform the quality analysis described above.

The code was initially generated with the support of Claude (AI tool) and subsequently reviewed, validated, and refined by the project group to ensure methodological consistency and accuracy of results.
